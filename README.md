# Production OEE & Downtime Analysis (Python)

Analysis of a 5-line manufacturing plant over 90 days (Jul-Sep 2026, 3 shifts/day, 1,350 line-shift records, 2,302 downtime events) to measure **OEE** and find the main causes of lost production using **Pareto** and **5M+1E** analysis.

> **Data note:** the dataset is synthetic (generated by `01_generate_data.py`) because real plant data is confidential. It imitates realistic patterns so the analysis workflow is the real deliverable.

## Tools
Python, Pandas, NumPy, Matplotlib (Power BI version of the dashboard can be built from the CSVs in `data/` and `results/`).

## Project structure
```
data/        production.csv, downtime_events.csv
results/     summary tables (OEE by line / shift / month, Pareto, 5M+1E)
charts/      5 charts used in the findings below
01_generate_data.py   builds the dataset
02_analysis.py        calculates OEE, Pareto, 5M+1E, draws charts
```
Run: `pip install pandas numpy matplotlib` then `python 01_generate_data.py` and `python 02_analysis.py`.

## Method
- **OEE = Availability x Performance x Quality**
  - Availability = run time / planned time
  - Performance = (total units x ideal cycle time) / run time
  - Quality = good units / total units
- Every downtime event is tagged with a **5M+1E** category (Man, Machine, Material, Method, Measurement, Environment).
- Results are sliced by line, shift, and month, then ranked with a Pareto chart.

## Key findings
1. **Plant OEE is 79.2%** (Availability 93.1%, Performance 88.5%, Quality 96.2%), below the 85% world-class benchmark. Performance is the weakest component.
2. **Line 3 is the biggest availability problem:** availability 89.8% (OEE 77.0%), with 6,333 min of Machine downtime, about 3.3x any other line (1,741-1,924 min).
3. **Line 5 has a material supply problem:** 3,452 min of Material downtime, about 2x the other lines (1,163-1,773 min).
4. **Line 4 has a quality problem:** quality 94.4% vs about 96.8% on the other lines.
5. **Night shift underperforms:** OEE 76.3% vs 80.7% on Morning/Evening, driven by lower performance (86.5% vs about 89.4%) and quality (94.9% vs 96.9%).
6. **Pareto:** Equipment breakdown alone causes 24.5% of all downtime, and the top 7 reasons cover 80%.
7. **5M+1E:** Machine (30.7%) and Material (20.8%) together cause about 51% of downtime; Man is third (16.8%).
8. **Trends:** Material shortage downtime jumped in August (2,883 min vs 1,871 in July and 1,307 in September). Calibration downtime almost doubled in September (1,107 min vs 594-655).

## Recommendations
- Start a preventive-maintenance and root-cause program on **Line 3** machines (largest single loss).
- Review supplier lead times and safety stock for **Line 5**, and investigate the August supplier issue.
- Add in-process quality checks on **Line 4** and review night-shift training, staffing, and supervision.
- Investigate why calibration stops increased in late September.
